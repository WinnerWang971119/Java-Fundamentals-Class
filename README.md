# Java Fundamentals · class files

Starter files for the in-class exercises, for FRC Team 10922 AMPED.

## Get the files (do this once)

1. Click the green **Code** button at the top of this page, then **Download ZIP**.
2. Unzip it somewhere you can find it, like your Desktop or Documents.
3. In VS Code choose **File → Open Folder** and pick the folder of the exercise
   you are working on (for example `11-multi-file`), not the whole unzipped folder.

When the next exercise starts, open its folder the same way.

## Which folder is for what

| Folder | Exercise / slide | The file you write |
|--------|------------------|--------------------|
| `11-multi-file/` | Exercise #11, "Three files, one project" | `StudentService.java` in `src/org/amped/service/` (already there; fill in the method) |
| `library-challenge/` | In-Class Challenge, "Library Management System" | `Library.java` in `src/` (already there; fill in the methods) |

Each folder has a `Main.java` you run to test your code; it prints PASS or FAIL for every case.
